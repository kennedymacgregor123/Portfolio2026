# Kennedy MacGregor — Portfolio 2026

The source for my design portfolio: a home page of projects, an About page, and a case study for each project.

## Projects

- **Citations:** a citation card for every number, quote and derived figure in a generated report.
- **Artifacts:** recurring, agent-generated reports built from a kit of report components and a library of templates.

The work shown was done at Vasco. The components on these pages are hand-built recreations made for this site. They are not the product's code, and all figures and names in them are sample data.

## Running it

```bash
npm install
npm run dev
```

`npm run build` type-checks and writes the static site to `dist/`.

## Built with

React, Vite, Tailwind CSS, Inter, and [Lucide](https://lucide.dev) icons (ISC licence).
